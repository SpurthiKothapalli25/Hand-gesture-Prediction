# Hand Gesture Recognition using Deep Learning

## 📌 Problem Statement

Develop a hand gesture recognition model that can accurately identify and classify different hand gestures from image or video data, enabling intuitive human-computer interaction and gesture-based control systems.

## 🎯 Objective

The objective of this project is to build a deep learning model that recognizes and classifies hand gestures from images.

## 🗂 Dataset

Hand Gesture Dataset

Classes:

* Ok
* PEACE
* fist
* palm
* thumbs up

## 🛠 Technologies Used

* Python
* TensorFlow / Keras
* NumPy
* Matplotlib
* Google Colab

## 🚀 Project Workflow

1. Collect and prepare dataset
2. Preprocess images
3. Train CNN model
4. Evaluate model performance
5. Predict hand gestures from uploaded images

## 📊 Output

The model predicts the hand gesture class and displays the prediction confidence.

Example:

Predicted Gesture: PEACE

Confidence: 50.30%
